# Караоке-строка

Android-приложение, которое узнаёт, какая песня играет в любом плеере на телефоне
(Spotify, YouTube Music, Яндекс Музыка, VK Музыка, Apple Music для Android, локальные плееры…),
находит её текст с таймкодами и показывает его **как в караоке**: текущая строка
закрашивается в такт музыке, а длинные строки плавно едут бегущей строкой.

Где показывается текст:
- **на заблокированном экране**: полноэкранное караоке открывается само, когда гаснет экран, если играет музыка;
- **плавающей строкой поверх всех приложений** (её можно перетаскивать, нажатие открывает полный экран);
- в самом приложении (предпросмотр).

## Как это работает

```
Плеер ──MediaSession──▶ MediaListenerService ──▶ MediaTracker (трек, позиция, пауза)
                         (доступ к уведомлениям)        │
                                                        ▼
                              lrclib.net ◀── LyricsController ──▶ LRC → KaraokeTimeline
                                                        │
                          ┌─────────────────────────────┼──────────────────────┐
                          ▼                             ▼                      ▼
                 LyricsActivity              FloatingOverlay            MainActivity
            (showWhenLocked, экран        (TYPE_APPLICATION_OVERLAY)    (предпросмотр)
               блокировки)
```

| Файл | Что делает |
|---|---|
| `MediaListenerService` | Служба доступа к уведомлениям. Только с этим доступом Android даёт читать медиа-сессии чужих плееров. Сами уведомления не читаются. |
| `MediaTracker` | Следит за всеми плеерами, выбирает тот, что играет, отдаёт название, исполнителя, длительность и позицию. |
| `LrcLibClient` | Ищет текст в [LRCLIB](https://lrclib.net), бесплатной открытой базе текстов с таймкодами (ключ API не нужен). |
| `LyricsController` | При смене трека загружает текст (с кешем и повторами при плохой сети). |
| `KaraokeLineView` | Рисует строку: закраска по прогрессу и бегущая строка. |
| `LyricsActivity` | Полноэкранное караоке поверх блокировки; кнопки плеера и подстройка синхронизации ±0,5 с. |
| `FloatingOverlay` | Плавающая строка поверх приложений. |
| `LockScreenLauncher` | Открывает караоке на блокировке (через разрешение наложения или full-screen-уведомление). |
| `core/` | Чистый Kotlin без Android: разбор LRC, расчёт текущей строки, очистка названий («(Official Video)», «- Remastered 2011», «feat.»), выбор лучшего результата поиска. Покрыт тестами. |

Если для песни есть только текст без таймкодов, строки распределяются по длительности
трека примерно; в этом случае на экране написано «≈ примерная синхронизация».

## Сборка

Нужны Android Studio (или JDK 17+ и Android SDK 35).

```bash
./gradlew :core:test          # тесты логики
./gradlew :app:assembleDebug  # APK: app/build/outputs/apk/debug/app-debug.apk
```

Без Android Studio можно собрать на GitHub: после push в репозиторий workflow
`.github/workflows/build.yml` соберёт APK и приложит его к запуску (раздел *Actions → Artifacts*).

Минимальная версия Android: 8.1 (API 27).

## Первый запуск на телефоне

1. **Доступ к уведомлениям**: кнопка в приложении → включить «Караоке-строка». Без этого трек не определяется.
2. **Поверх других приложений**: нужно для экрана блокировки и плавающей строки.
3. Включите музыку и заблокируйте телефон. При включении экрана текст уже будет на экране блокировки.

Xiaomi / Redmi / POCO: в настройках приложения → «Другие разрешения» включите
«Экран блокировки» и «Отображать всплывающие окна, когда запущено в фоне».
На Samsung, Huawei, Honor, Xiaomi также стоит отключить оптимизацию батареи для приложения.

## А iOS?

Сделать то же самое на iPhone **нельзя**: это ограничение iOS, а не приложения.

- iOS не даёт сторонним приложениям узнать, что играет в Spotify, Яндекс Музыке и других плеерах.
  Доступен только системный плеер Apple Music (`MPMusicPlayerController.systemMusicPlayer`).
- На экран блокировки нельзя вывести своё окно. Есть только Live Activity (виджет на блокировке),
  и он обновляется не чаще чем раз в несколько секунд через push или фоновые задачи,
  поэтому плавная закраска строк в нём невозможна.

Возможный компромисс для iOS: приложение, которое работает только с Apple Music (и со Spotify
через Spotify iOS SDK), показывает караоке внутри себя, а на экране блокировки показывает Live Activity
с текущей строкой, обновляемой раз в несколько секунд.
